Database Explorer

Campus Life database. 4 tables.
PK primary key FK foreign key (points to a column in another table)
Database Schema and relationship diagram
  • One club can host many events. Events.club_id points to Clubs.club_id.
  • One student can register for many events, and one event can have many students.
  • Registrations connects the two. Registrations.student_id points to Students.student_id, and Registrations.event_id points to Events.event_id.
  • A club can have zero events, an event can have zero registrations, and a student can have zero registrations.
SQL Reference Card
SELECT / FROM
SELECT first_name FROM Students;

SELECT picks the columns. FROM names the table. Use * for all columns.

WHERE
SELECT * FROM Clubs
WHERE category = 'Technology';

Keeps only the rows that match. Text goes in single quotes.

AND / OR
WHERE major = 'Data Science'
  AND year_level = 'Junior'

AND needs both tests true. OR needs at least one.

ORDER BY
SELECT * FROM Events
ORDER BY event_date DESC;

Sorts the result. ASC is A to Z (default). DESC is Z to A.

GROUP BY
SELECT category, COUNT(*)
FROM Clubs
GROUP BY category;

Makes one group for each different value, then summarizes each group.

COUNT()
COUNT(*)          -- counts rows
COUNT(column)     -- skips NULLs

COUNT(*) counts every row. COUNT(column) counts only rows where that column is not NULL.

INNER JOIN
SELECT Students.first_name, Registrations.event_id
FROM Students
JOIN Registrations
ON Students.student_id = Registrations.student_id;

Keeps only the rows that have a match in both tables.

LEFT JOIN
SELECT Students.first_name, Registrations.event_id
FROM Students
LEFT JOIN Registrations
ON Students.student_id = Registrations.student_id;

Keeps every row from the left table. Missing matches show NULL.

SQLite versus MySQL

This site runs SQLite in your browser. Most basics are the same as MySQL. Three differences to know. First, = on text is case-sensitive in SQLite, so 'senior' does not match 'Senior'. MySQL usually ignores case. Second, SQLite lets you select a column that is not in GROUP BY, while MySQL normally shows an error. Third, always use single quotes for text values.
